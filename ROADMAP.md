# Roadmap

AniDōki is built in small phases that can each be verified on their own. Each phase is planned in detail against the latest code before work starts, so the scope of later phases may change.

| Phase | Scope | Status |
|---|---|---|
| 1 | Uninstall cleanup, dashboard entry and icon, card artwork, README logo | Shipped |
| 2 | Visual refresh and a basic toast for confirmed tracker updates | Shipped |
| 2 follow-up | Manual watched confirmation and personal Discord embeds | Shipped |
| 2.5 | Hardening: secure storage for tracker tokens, background syncs, and reliability fixes | Planned |
| 3 | Episode-range mappings, shared defaults and personal overrides | Planned |
| 4 | Read-only manual-sync preview, then applying selected changes | Planned |
| 5 | Live playback updates, per-user thresholds, reliability and history, adding unlisted anime | Planned |
| 6 | Progress popup; supported scores, dates and rewatches | Planned |
| 7 | Richer notification states and actions | Planned |

Some principles hold across every phase:

- Never silently reduce progress on a tracker.
- Re-check current state before applying a change.
- Treat a rewatch as its own cycle.
- Report only results the tracker confirmed.

Have an idea or a problem that doesn't fit here? Open an issue.
